# Changelog of the reproducibility archive

Each release is an export of the authors' working repository at the commit in `SOURCE_COMMIT`. The version number says what changed against the release before it: the first digit when a result file changed, so that numbers in the paper differ; the second when the paper's text or the set of files changed with the same numbers; the third for the archive's own documentation and metadata only.

## 1.0.0

First archived release. Results as measured on the Linux VM (speed and memory) and on a laptop (tie experiment). The paper source is the text after the authors' final review; it cites this archive by its repository address, because the archive's DOI did not exist until this release was made. The next release adds the DOI to the paper and will say here which release matches the paper as submitted.
