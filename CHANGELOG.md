# Changelog of the reproducibility archive

Each release is an export of the authors' working repository at the commit in `SOURCE_COMMIT`. The version number says what changed against the release before it: the first digit when a result file changed, so that numbers in the paper differ; the second when the paper's text or the set of files changed with the same numbers; the third for the archive's own documentation and metadata only.

The DOI [10.5281/zenodo.23210002](https://doi.org/10.5281/zenodo.23210002) covers every release and resolves to the latest.

## 1.1.0

The paper as submitted to arXiv. Against 1.0.0, the paper cites this archive by its DOI instead of its repository address, and the README and `CITATION.cff` carry the DOI. No result file changed, so every number in the paper is the same.

## 1.0.0

First archived release ([10.5281/zenodo.23210003](https://doi.org/10.5281/zenodo.23210003)). Results as measured on the Linux VM (speed and memory) and on a laptop (tie experiment). The paper source is the text after the authors' final review; it cites this archive by its repository address, because the archive's DOI did not exist until this release was made.
